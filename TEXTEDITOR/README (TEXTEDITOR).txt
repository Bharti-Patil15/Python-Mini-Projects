# Simple Text Editor

## 📌 Project Description
Simple Text Editor is a desktop-based text editing application developed using Python and Tkinter. It provides a user-friendly graphical interface that allows users to create, open, edit, and save text files.

It includes useful features such as Find and Replace, Undo and Redo, Dark Mode, Font Formatting, Word Count, and Auto Save.

## 🚀 Features

New File: Create a new text document.

Open File: Open existing `.txt` files.

Save File: Save changes to the current file.

Save As: Save a file with a different name or location.

Undo and Redo: Undo or redo editing operations.

Cut, Copy and Paste: Perform basic text editing operations.

Find and Replace: Search for words and replace all matching words.

Dark Mode: Switch between light and dark themes.

Font Size: Change the text font size.

Bold, Italic and Underline: Apply text formatting.

Date and Time: Insert the current date and time.

Word and Character Count: Display the total number of words and characters.

Auto Save: Automatically save changes every 30 seconds.

Unsaved Changes Warning: Get a confirmation before closing or creating a new file with unsaved changes.

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python main.py
```

5. The Simple Text Editor application will open.

Note: Replace `main.py` with your actual Python filename if it is different.
