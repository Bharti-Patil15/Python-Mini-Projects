# 🎯 Guessing Number Game

## 📌 Project Description

The Guessing Number Game is a simple Python-based mini project where the computer randomly selects a number between 1 and 50, and the user has to guess the correct number.

The program provides hints after each guess:

* Too Low: If the guessed number is smaller than the secret number.
* Too High: If the guessed number is greater than the secret number.
* You Won: If the user guesses the correct number.

The game continues until the user guesses the correct number.

 🛠️ Technologies Used

* Python
* Random Module
* While Loop
* Conditional Statements
* User Input

 ▶️ How to Run

1. Clone this repository.
2. Open the project in VS Code or any Python IDE.
3. Run the Python file.

```bash
python guessing_game.py
```
