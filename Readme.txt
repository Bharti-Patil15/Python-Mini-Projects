# Student Management System

## Project Description
The Student Management System is a simple console-based Python project that helps users manage student records. It allows users to add, view, update, delete student details, and check their results based on marks.

This project is developed using Core Python concepts, especially dictionaries, loops, conditional statements, and user input.

## Features

1. **Add Student:** Add a new student with their name and marks.
2. **View Students:** Display all student records.
3. **Check Results:** Check whether a student has passed or failed.
4. **Update Student:** Update the marks of an existing student.
5. **Delete Student:** Delete a student record.
6. **Exit:** Exit the program.

## Technologies Used

- Python
- Dictionary
- While Loop
- If-Else Statements
- For Loop
- User Input and Output

## How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python student_management.py
```

## Passing Criteria

- Marks greater than or equal to 40: **Pass**
- Marks below 40: **Fail**
